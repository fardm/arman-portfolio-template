# سایت پورتفولیو آرمان

یک پورتفولیوی شخصی و کاملاً استاتیک با Next.js و TypeScript.

## پیش نیاز
پیش نیاز های استفاده از این پروژه:
1. نصب [git](https://git-scm.com/)
2. نصب [nude.js](https://nodejs.org/en/download)
3. اکانت گیت هاب

## نصب آسان
برای نصب و راه‌اندازی پروژه، مراحل زیر را انجام دهید:

روی فایل setup.bat کلیک کنید.
یک پنجره برای ورود به GitHub باز می‌شود. از طریق مرورگر وارد حساب GitHub خود شوید.
پس از ورود، به پنجره CMD برگردید.
نام کاربری و ایمیل حساب GitHub خود را وارد کنید.
در ادامه، وابستگی‌های موردنیاز پروژه به‌صورت خودکار نصب می‌شوند.

پس از اتمام مراحل، نصب کامل است. 🎉

اکنون می‌توانید فایل admin-panel.bat را اجرا کرده و پنل مدیریت را باز کنید.

## نصب دستی

اگر می‌خواهید مراحل نصب را به‌صورت دستی انجام دهید:

1. مطمئن شوید به **GitHub** دسترسی دارید و `username` و `email` مربوط به Git روی سیستم شما تنظیم شده‌اند.
2. وابستگی‌های پروژه را نصب کنید:

```bash
npm install
```

3. برای اجرای داشبورد مدیریت، دستور زیر را اجرا کنید:

```bash
npm run cms
```

4. سپس پنل مدیریت را در آدرس زیر باز کنید:

`http://localhost:3100`

> **نکته:** پنل مدیریت فقط به‌صورت محلی روی کامپیوتر شما اجرا می‌شود و برای مدیریت فایل‌های پروژه، دسترسی خواندن و نوشتن دارد.

## امکانات
از طریق پنل مدیریت می‌توانید تمامی موارد سایت را کترل کنید:
- برگه ها
- پروژه ها
- دسته بندی ها
- رسانه ها
- تنظیمات

برای مشاهده سایت از گزینه "پیش نمایش" استفاده کنید. این گزینه در واقع دستور زیر را اجرا می کند:
```shell
npm run dev
```

برای انتشار در گیت هاب هم از گزینه "انتشار" استفاده کنید. این گزینه دستور `git status` را اجرا میکند. تغییرات را شناسایی کرده آنها را commit & push می کند.
