# سایت پورتفولیو آرمان

یک پورتفولیوی شخصی و کاملاً استاتیک با Next.js و TypeScript.

## استفاده
پیش نیاز های استفاده از این پروژه:
1. نصب git: https://git-scm.com/
2. نصب nude.js: https://nodejs.org/en/download 
3. اکانت گیت هاب

## نصب آسان
روی فایل setup.bat کلیک کنید این فایل عملیات لاگین، تنظیم کانفیگ گیت و نصب وابستگی ها را انجام می دهد.
یک پنجره باز می شود برای لاگین به گیت هاب از مرورگر لاگین کنید
بعد بر گردید به cmd
یوزرنیم و ایمیل اکانت گیت هاب را وارد کنید
بعد وابستگی ها نصب می شود.
تمام
حالا میتوانید فایل admin-panel.bat را اجرا کنید.



## نصب دستی
مطمئن شوید که به گیت هاب دسترسی دارید و کانفیگ یوزرنیم و ایمیل ست شده است.
وابستگی ها را نصب کنید
```bash
npm install
```

برای باز کردن داشبورد این دستور را بزنید

```bash
npm run cms
```

سپس پنل مدیریت را در `http://localhost:3100` باز کنید. این پنل فقط روی کامپیوتر شما اجرا می‌شود و به فایل‌های پروژه دسترسی خواندن و نوشتن دارد.

از CMS می‌توانید پروژه‌ها، دسته‌ها، رزومه، تنظیمات سایت، پوسته، فونت و رسانه‌ها را مدیریت کنید. دکمه «اجرای پیش‌نمایش» سرور توسعه را اجرا می‌کند و «ساخت استاتیک» محتوای سایت را اعتبارسنجی کرده و خروجی نهایی را می‌سازد.

## مدیریت محتوا

- پروژه‌ها در `content/projects/` به‌صورت Markdown با frontmatter ذخیره می‌شوند.
- دسته‌ها در `content/categories.json` نگهداری می‌شوند.
- رزومه در `content/resume.json` نگهداری می‌شود.
- تنظیمات سایت و رنگ‌ها در `content/site.json` ذخیره می‌شوند.
- رسانه‌ها در `public/media/` قرار می‌گیرند.

## اعتبارسنجی و ساخت

```bash
npm run validate
npm run build
```

ساخت سایت تمام مسیرهای پروژه‌ها، صفحات عمومی، sitemap و robots.txt را تولید می‌کند و خروجی مستقل را در `out/` می‌گذارد.

## انتشار در GitHub Pages
برای انتشار در گیت هاب در پنل مدیریت از بخش انتشار استفاده کنید.
