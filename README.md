# پورتفولیوی فارسی

یک پورتفولیوی شخصی فارسی، راست‌به‌چپ و کاملاً استاتیک با Next.js و TypeScript. سایت عمومی از فایل‌های داخل `content/` خوانده می‌شود و خروجی نهایی در `out/` ساخته می‌شود.

## نصب

```bash
npm install
```

## اجرای سایت عمومی

```bash
npm run dev
```

سایت در `http://localhost:3000` اجرا می‌شود.

## اجرای CMS محلی

```bash
npm run cms
```

سپس پنل مدیریت را در `http://localhost:3100` باز کنید. این پنل فقط روی کامپیوتر شما اجرا می‌شود و به فایل‌های پروژه دسترسی خواندن و نوشتن دارد.

از CMS می‌توانید پروژه‌ها، دسته‌ها، رزومه، تنظیمات سایت، پوسته، فونت و رسانه‌ها را مدیریت کنید. دکمه «اجرای پیش‌نمایش» سرور توسعه را اجرا می‌کند و «ساخت استاتیک» محتوای سایت را اعتبارسنجی کرده و خروجی نهایی را می‌سازد.

## مدیریت محتوا

- پروژه‌ها در `content/projects/` به‌صورت Markdown با frontmatter ذخیره می‌شوند.
- دسته‌ها در `content/categories.json` نگهداری می‌شوند.
- رزومه در `content/resume.json` نگهداری می‌شود.
- تنظیمات سایت و رنگ‌ها در `content/site.json` ذخیره می‌شوند.
- رسانه‌ها در `public/media/` قرار می‌گیرند.

## اعتبارسنجی و ساخت

```bash
npm run validate
npm run build
```

ساخت سایت تمام مسیرهای پروژه‌ها، صفحات عمومی، sitemap و robots.txt را تولید می‌کند و خروجی مستقل را در `out/` می‌گذارد.

## انتشار در GitHub Pages

محتویات پوشه `out/` را روی GitHub Pages منتشر کنید. اگر پروژه در یک repository با نام غیر از دامنه اصلی منتشر می‌شود، هنگام ساخت مقدار `NEXT_PUBLIC_BASE_PATH` را برابر نام repository قرار دهید تا مسیر فایل‌ها درست شود.

سایت خروجی به Node.js، دیتابیس یا سرور نیاز ندارد.
