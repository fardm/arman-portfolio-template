# سایت پورتفولیو آرمان

یک پورتفولیوی شخصی و کاملاً استاتیک با Next.js و TypeScript.

## پیش نیاز
پیش نیاز های استفاده از این پروژه:
1. نصب [git](https://git-scm.com/)
2. نصب [nude.js](https://nodejs.org/en/download)
3. اکانت گیت هاب

## نحوه استفاده

### گام اول: دانلود
1. توی صفحه همین ریپازتوری روی دکه use this template کلیک کنید
2. گزینه reate new repo رو کلیک کنید.
3. یه اسم برای ریپوی خودتون انتخاب کنید و کریت رو بزنید.
4. بعدش پروژه رو کلون کنید


## گام دوم: نصب
برای نصب و راه‌اندازی پروژه، مراحل زیر را انجام دهید:

1. روی فایل setup.bat کلیک کنید.
2. یک پنجره برای ورود به GitHub باز می‌شود. از طریق مرورگر وارد حساب GitHub خود شوید.
3. پس از ورود، به پنجره CMD برگردید.
4. نام کاربری و ایمیل حساب GitHub خود را وارد کنید.
5. در ادامه، وابستگی‌های موردنیاز پروژه به‌صورت خودکار نصب می‌شوند.

پس از اتمام مراحل، نصب کامل است. 

### گام سوم: ویرایش
اکنون می‌توانید فایل `admin-panel.bat` را اجرا کرده و پنل مدیریت را باز کنید.
از طریق پنل مدیریت می‌توانید تمامی موارد سایت را کترل کنید:
- برگه ها
- پروژه ها
- دسته بندی ها
- رسانه ها
- تنظیمات

برای مشاهده سایت میتوانید از گزینه پیش نمایش استفاده کنید.

## انتشار
برای انتشار ابتدا به ریپوی گیت هاب بروید.
روی سیتینگ بزنید بخش pages. سورس رو بذارید روی گیت هاب اکشنز
اگر از دامنه سفارشی میخواید استفاده کنید توی فیلد کاستوم دامین دامنه خودتون رو وارد کیند

به پنل مدیریت برید. به بخش انتشار برید. 

آدرس سایت تون رو انتخاب کنید اگر دامین سفارشی استفاده نکردید بذاری روی همون حالت آدرس پیشفرض گیت هاب. اگر وارد کردید حالت رو بذارید روی دامنه سفارشی و دامنه خودتون رو توی فیلد وارد کنید.

توی باکس بعدی تغییراتی که اعمال کردید اینجا بررسی شده و نمایش داده میشه. روی دکمه انتشار بزنید تا به گیت هاب ارسال بشه. احتمالا دوباره یه پنجره باز میشه برای اینکه به گیت هاب لاگین کنید.
بعد از اینکه انتشار موفق بود به گیت هاب برید تل اکشن و ضقعیت اکشن رو بررسی کنید باید تیک سبز بگیره
توی کارت دپلوی آدرس سایت رو نوشته روش کلیک کنید تا سایت رو ببینید
